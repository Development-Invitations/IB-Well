# Ishonchli Buxgalter — сайт + личный кабинет + админка

## Что внутри

- Публичный сайт (5 страниц): `index.php`, `courses.php`, `about.php`, `blog.php`, `contacts.php`
- Регистрация/вход для пользователей, которые оставляют заявки: `register.php`, `login.php`, `logout.php`, `account.php`
- Обработчик заявок с отправкой в Telegram: `apply.php`
- Админка: папка `admin/`
- «База данных» — обычные JSON-файлы в папке `data/` (без MySQL), как и просили:
  - `data/users.json` — зарегистрированные пользователи
  - `data/leads.json` — заявки (на курс или на консультацию)
  - `data/courses.json` — курсы (редактируются в админке, показываются на сайте)
  - `data/posts.json` — статьи блога (редактируются в админке)
  - `data/settings.json` — токены двух Telegram-ботов
  - `data/admin.json` — логин/хеш пароля администратора

## Установка на хостинг

1. Залейте все файлы на хостинг (нужен PHP 8+, ничего больше не требуется).
2. Убедитесь, что папка `data/` доступна на **запись** (chmod 755/775) — туда пишутся заявки, пользователи и т.д.
3. Откройте `https://ваш-домен/install.php` — задайте логин и пароль администратора.
4. После этого зайдите в `https://ваш-домен/admin/login.php` и **удалите `install.php` с сервера** — он больше не нужен и представляет риск, если его оставить.
5. Зайдите в Админка → Настройки и вставьте токены двух Telegram-ботов (через @BotFather) и chat_id, куда слать заявки:
   - **Бот заявок на курсы** — для заявок на конкретный курс.
   - **Бот заявок на консультацию** — когда в форме выбрано «Ещё не решил(а), нужна консультация».

## Админка на поддомене (panel1.eskiz.uz)

Если планируете открыть админку на отдельном поддомене — в панели хостинга создайте
поддомен и укажите его корневую директорию (document root) на папку `admin/` внутри
файлов сайта (НЕ отдельная копия). Тогда:
- админка и основной сайт продолжат работать с одними и теми же файлами в `data/`;
- все ссылки внутри `admin/` уже сделаны относительными, так что это сработает без правок кода;
- в `includes/config.php` поменяйте константу `MAIN_SITE_URL`, если домен основного сайта отличается от `ishonchli-buxgalter.uz` — она используется только для кнопки «Открыть сайт» в боковом меню.

## Как это работает без базы данных

Все записи (пользователи, заявки, курсы, статьи, настройки) — просто JSON-массивы
в файлах `data/*.json`. Чтение/запись идёт через `read_json()` / `write_json()` в
`includes/config.php`, с блокировкой файла (`flock`), чтобы две одновременные заявки
не затёрли друг друга. Папка `data/` закрыта от прямого доступа через `.htaccess`
(на Apache) — обязательно проверьте это на своём хостинге, если сервер не Apache.

## Логика заявок и ботов

`contacts.php` показывает форму, только если пользователь вошёл в аккаунт (иначе —
кнопки «Войти» / «Зарегистрироваться»). При отправке `apply.php`:
1. сохраняет заявку в `data/leads.json`, привязывая к `user_id`;
2. определяет тип — «курс» или «консультация» (по выбранному пункту в списке);
3. отправляет уведомление в соответствующего Telegram-бота через Bot API.

В личном кабинете (`account.php`) пользователь видит свои заявки и их статус
(«Новая» / «Связались» / «Записан(а)») — статус меняется в админке на странице «Заявки».

## Дизайн

Цветовая палитра и вёрстка полностью повторяют публичную часть сайта — админка
использует тот же `style.css` (продублирован в `admin/style.css` для случая
поддомена с отдельным document root).
